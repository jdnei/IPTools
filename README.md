# IP 与网络检测工具箱(2026年10月31日更新)

> 汇总常用的 IP 查询、归属地、BGP、风险信誉、隐私泄露、连通性测速及公网资产检查工具。
> 已移除站内导航、推广入口与站内链接；工具用途为简述，实际结果以对应服务为准。

## 使用提示

- 对比直连与代理开启后的出口 IP，避免将本机网络和代理节点混淆。
- IP 的地理位置和风险评分可能因数据库不同而不同，建议交叉验证。
- 排查网络故障时结合多时段、多运营商的 Ping、MTR 和 TCP 结果。
- DNS、WebRTC、IPv6 泄露和 IP 信誉是不同维度，应分别检测。
- 公网资产测绘仅用于自己拥有或明确获授权的系统。

## VPS / 代理出口排查参考流程

1. **识别当前出口**：先用 [Ping0.cc](https://ping0.cc/) 或 [IP.SKK](https://ip.skk.moe/) 查看公网 IP、ASN 和网络类型。
2. **交叉检查 IP 信誉**：结合 [Scamalytics](https://scamalytics.com/ip)、[AbuseIPDB](https://www.abuseipdb.com/) 等数据源；单一评分不能保证目标服务可用。
3. **核对网络归属**：使用 [BGP.Tools](https://bgp.tools/) 等查看 AS 和上游，不能仅凭一个 ASN 判断完整线路质量。
4. **测试线路**：通过 [ITDOG](https://www.itdog.cn/) 和 [tcp.cm](https://tcp.cm/) 多点测试延迟、路由和端口。
5. **检查隐私泄露**：使用 [IPLeak](https://ipleak.net/) 或 [DNS Leak Test](https://www.dnsleaktest.com/) 验证 DNS、WebRTC 与 IPv6。

> **注意**：网站检测结果是排障线索，不代表账号、AI 服务或流媒体平台一定可用。个别服务可能要求登录、付费，或因地区及网络限制无法访问。
