# جعبه‌ابزار بررسی IP و شبکه(به‌روزرسانی 11 نوامبر 2026)

> مجموعه‌ای از ابزارهای کاربردی برای بررسی آدرس IP، موقعیت جغرافیایی، مسیریابی BGP، امتیاز ریسک و اعتبار IP، شناسایی نشت اطلاعات خصوصی، آزمایش اتصال و سرعت شبکه و بررسی دارایی‌های در معرض اینترنت عمومی.
>
> بخش‌های ناوبری داخلی سایت، ورودی‌های تبلیغاتی و لینک‌های داخلی حذف شده‌اند. توضیحات ابزارها خلاصه هستند و نتایج واقعی به سرویس ارائه‌دهنده هر ابزار بستگی دارد.

## نکات استفاده

- آدرس IP خروجی خود را قبل و بعد از فعال‌سازی VPN یا پروکسی مقایسه کنید تا شبکه محلی خود را با سرور پروکسی اشتباه نگیرید.
- موقعیت جغرافیایی و امتیاز ریسک IP ممکن است در پایگاه‌های داده مختلف متفاوت باشد؛ بهتر است نتایج را از چند منبع بررسی کنید.
- هنگام عیب‌یابی شبکه، نتایج Ping، MTR و TCP را در زمان‌های مختلف و از طریق اپراتورهای اینترنت متفاوت مقایسه کنید.
- نشت DNS، WebRTC، IPv6 و اعتبار IP جنبه‌های متفاوتی از امنیت و حریم خصوصی هستند و باید جداگانه آزمایش شوند.
- ابزارهای شناسایی دارایی‌های متصل به اینترنت عمومی را فقط برای سیستم‌هایی استفاده کنید که مالک آن‌ها هستید یا مجوز صریح بررسی آن‌ها را دارید.

## راهنمای عیب‌یابی VPS و IP خروجی پروکسی

1. **شناسایی IP خروجی فعلی:** ابتدا از [Ping0.cc](https://ping0.cc/) یا [IP.SKK](https://ip.skk.moe/) برای بررسی آدرس IP عمومی، ASN و نوع شبکه استفاده کنید.

2. **بررسی اعتبار IP از چند منبع:** اطلاعات [Scamalytics](https://scamalytics.com/ip)، [AbuseIPDB](https://www.abuseipdb.com/) و سایر منابع را مقایسه کنید. یک امتیاز ریسک به‌تنهایی نمی‌تواند دسترسی به سرویس موردنظر را تضمین کند.

3. **تأیید مالکیت و وابستگی شبکه:** با استفاده از [BGP.Tools](https://bgp.tools/) یا ابزارهای مشابه، سیستم خودمختار و ارائه‌دهندگان بالادستی را بررسی کنید. تنها یک ASN برای ارزیابی کیفیت کامل مسیر شبکه کافی نیست.

4. **آزمایش مسیرهای شبکه:** از [ITDOG](https://www.itdog.cn/) و [tcp.cm](https://tcp.cm/) برای آزمایش تأخیر، مسیریابی و اتصال درگاه‌ها از چندین مکان استفاده کنید.

5. **بررسی نشت اطلاعات خصوصی:** با استفاده از [IPLeak](https://ipleak.net/) یا [DNS Leak Test](https://www.dnsleaktest.com/) عملکرد DNS، WebRTC و IPv6 را بررسی کنید.

> **توجه:** نتایج این وب‌سایت‌ها فقط نشانه‌هایی برای عیب‌یابی هستند و تضمین نمی‌کنند که حساب کاربری، سرویس هوش مصنوعی یا پلتفرم پخش آنلاین حتماً کار کند. برخی سرویس‌ها ممکن است به ورود به حساب یا پرداخت هزینه نیاز داشته باشند یا به دلیل محدودیت‌های منطقه‌ای و شبکه‌ای در دسترس نباشند.
